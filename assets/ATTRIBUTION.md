# Bundled image assets

- `sample_photo.jpg`: Rear Admiral Grace Hopper, 1984, U.S. Navy photograph.
  Public domain U.S. federal government work. Copied without modification from
  Matplotlib's bundled `mpl-data/sample_data/grace_hopper.jpg` in this environment.
  Source identification: https://commons.wikimedia.org/wiki/File:Grace_Hopper.jpg
  This is an ordinary 2D photograph. No inferred depth or stereo reconstruction
  is bundled with it.
- `stereo_left.png`, `stereo_right.png`, `stereo_test_sbs.png`,
  `stereo_test.json`: original deterministic calibration artwork created for this
  project and dedicated to the public domain under CC0-1.0.
  Generated by `tools/generate_calibration.py` using Pillow and the DejaVu Sans
  font installed on the development machine. No font file is bundled.

The calibration artwork is a known stereo fixture, not output of AI conversion.
